## 3. 四项改进的假设与受控逻辑

每项按"改什么 / 控制什么 / 预期什么 / 怎么对照"四句话写：

| 方向 | 改动 | 控制变量 | 预期 | 对照方式 |
| :--- | :--- | :--- | :--- | :--- |
| A 提示词 | 头部加输出契约 `strict_fmt` | 题目、选项、解码、抽取规则全不动 | 格式有效率↑、输出变短 | 同机 `base` vs `strict_fmt` |
| B 少样本 | 每科 2 个 dev 示例 | 示例数量固定 2、顺序固定 | 准确率小幅↑、prompt 变长 | 同机 0-shot vs 2-shot |
| C 投票 | 3 次采样多数投票 | 只改采样，其余不变 | 准确率↑但耗时 ×3 | 同机 greedy vs 3-vote |
| D 批处理 | batch_size=8 + inference_mode | prompt/解码逐字节一致 | 耗时↓、准确率不变 | 同机 bs=1 vs bs=8 |

### 成员 C：基线与三次采样投票对照

两次运行使用相同评测集（`subset_md5=496fefb60ec2610b6ff15115320b823d`）、同一模型、设备、精度、模板和 `max_new_tokens=16`。投票实验把 greedy 改为 `do_sample=true`，每题生成 3 次后投票。

| 指标 | 基线 `exp00_base_C` | 投票 `exp03_voting` |
| :--- | ---: | ---: |
| 正确题数 / 准确率 | 16 / 200（8.00%） | 42 / 200（21.00%） |
| 格式有效题数 / 格式有效率 | 42 / 200（21.00%） | 116 / 200（58.00%） |
| 截断题数 / 截断率 | 112 / 200（56.00%） | 165 / 200（82.50%） |
| 生成次数 | 200 | 600 |
| 输出 token 总数 | 2,497 | 7,404 |
| 平均每次生成 token | 12.49 | 12.34 |
| 生成总耗时 | 214.835 秒 | 694.059 秒 |
| 平均每题耗时 | 1.0742 秒 | 3.4703 秒 |

逐题配对后，33 题由基线错转为投票对，7 题由基线对转为投票错，净增 26 题（准确率 +13 个百分点）。格式有效率提高 37 个百分点，但截断率也提高 26.5 个百分点；投票耗时约为基线的 3.23 倍。输出 token 总量约为 2.96 倍，主要来自每题生成三次；单次生成平均 token 数基本相近。由于此对照同时从 greedy 改为随机采样并增加到三次生成，结果只能说明“采样 + 多次生成 + 投票”整体策略的效果，不能单独归因于多数投票规则。

| 学科 | 基线准确率 | 投票准确率 |
| :--- | ---: | ---: |
| college_economics | 7.50% | 27.50% |
| accountant | 10.00% | 17.50% |
| physician | 5.00% | 22.50% |
| civil_servant | 2.50% | 12.50% |
| urban_and_rural_planner | 15.00% | 25.00% |

投票统计：600 张票中 423 张无效（`sample_answers` 中为 `null`，70.5%）；188 题至少含一张无效票，其中 84 题三张全无效、104 题部分无效，另有 12 题三张均有效。15 题发生平票，按当前规则平票题中 5 题最终答对、10 题答错。截断率按“每题三次输出中至少一次截断”统计。

## 7. 负结果、局限与下一步

- 哪些改进没效果、为什么（假设不成立 / 0.5B 能力不足 / 输出被截断 / 采样噪声）；
- 局限：子集只有 200 题、学科偏职业资格、模型预训练可能接触过公开基准（不能声称无污染）；
- 下一步怎么验证：扩学科、换 1.5B、加自检修正、重复多 seed 报均值与波动。

成员 C 的投票结果同时显示准确率与格式有效率提高、但截断率和耗时明显增加；无效票占比高，且有 7 题由基线正确变为投票错误。`vote.local.json` 的模型 revision 未固定；投票日志的 `git_commit` 记录为 `25f0484-dirty`。报告应保留这些复现限制，并避免把本次结果描述为多数投票规则本身的单独因果效果。
