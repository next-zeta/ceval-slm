## 3. 判定标准

- **一次跑通**：按 README 从零开始、不改任何命令与文件即可得到 summary；
- **结果一致**：准确率完全相同（同 commit、同数据、同设备）；若设备不同，允许耗时不同，
  但**准确率必须一致**——不一致说明存在未记录的随机性或代码差异；
- **差异说明**：写清是"设备不同""Python/torch 版本不同"还是"README 缺步骤"。
