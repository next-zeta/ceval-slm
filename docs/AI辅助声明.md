# AI 辅助使用声明

> 课程 PDF §10.7 允许使用 AI 编程辅助，但要求如实说明用途，且成员须能解释关键代码。
> 本声明在 Day 4 终检时按实际情况补全；**不得**把 AI 生成的结果当成实验数据。

## 1. 使用了哪些环节

| 环节 | 是否使用 | 具体用途 | 人工复核人 |
| :--- | :--- | :--- | :--- |
| 仓库骨架与目录结构 | 是 | 生成 `src/` 下四个模块的初版框架、`configs/` 与 README 结构 | |
| 脚本实现 | 是 | `prepare_data.py` 抽样与自检、`run_eval.py` 推理与计时框架 | |
| 提示模板措辞 | 是 | `base` / `strict_fmt` / `fewshot` 模板初稿 | |
| 文档排版 | 是 | 实验记录表、复现记录表的表格结构与措辞 | |
| 结果核对 | 是 | `report.py` 反算总表的逻辑 | |
| **实验数据生成** | **否** | 所有准确率/耗时均来自组员本人在自有设备上的真实运行 | 全员 |

## 2. 声明正文

> 本组在以下环节使用了 AI 编程辅助：① 代码骨架与配置文件生成；② 实验记录表与文档排版；
> ③ 结果核对脚本。所有实验数据均来自组员本人在自有设备上的真实运行，AI 未参与结果生成或
> 选择性报告。四名成员均可独立解释所负责模块的代码、评分规则与实验设计。
