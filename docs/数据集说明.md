# 数据集说明：C-Eval 200 题子集是怎么来的

> 本文件是子集的"出生证明"。任何替换题目、改动抽样规则的行为都必须在这里记录，
> 并且**重新跑全部实验**（旧结果作废，不能只重跑答错的题）。

## 1. 只用 val 划分

C-Eval 的 `test` 划分答案不由官方公开（正式评测要提交到榜单），`dev` 每题只有 5 条、
专门用作少样本示例。因此：

- 评测题：**只从 `val` 抽**，答案公开、可本地算分；
- 少样本示例：**只从 `dev` 抽**，与评测题零交集；
- 不碰 `test`。

## 2. 学科选择：原方案不可行，已改（v0.3）

原《方案.md》v0.2 选的是 `computer_network / high_school_physics / college_medicine /
modern_chinese_history / law`，要求每科 40 题。核对了 `ceval/ceval-exam` 的真实题量后发现问题：

| 原定学科 | val 实际题数 | 能否抽 40 题 |
| :--- | ---: | :--- |
| `computer_network` | 19 | ✗ |
| `high_school_physics` | 19 | ✗ |
| `college_medicine` | — | ✗ 该学科不存在（只有 `clinical_medicine` / `basic_medicine` / `physician`） |
| `modern_chinese_history` | 23 | ✗ |
| `law` | 24 | ✗ |

C-Eval 的 val 总量 1346 题摊到 52 个学科，多数只有 19~24 题；**只有 7 个学科 val ≥ 40**：

| 学科 | val | test | 备注 |
| :--- | ---: | ---: | :--- |
| `college_economics` | 55 | 497 | 经济学 |
| `accountant` | 49 | 443 | 会计 |
| `physician` | 49 | 443 | 医师 |
| `tax_accountant` | 49 | 443 | 税务师 |

**最终选定 5 科（覆盖经管 / 医学 / 公共管理 / 工程规划）**：

| 学科 | val 题量 | 抽取 |
| :--- | ---: | ---: |
| `college_economics` | 55 | 40 |

| `physician` | 49 | 40 |
| `civil_servant` | 47 | 40 |
| `urban_and_rural_planner` | 46 | 40 |

合计 **200 题**，满足"≥200 题、≥5 学科、每科 ≥20 题"的硬指标，且全部来自 val。

> 代价（如实写进报告）：学科偏"职业资格 / 社科经管"，缺少理工与人文覆盖；
> 所有结论只对本组这个子集成立，**不能**表述为完整 C-Eval 成绩。

## 3. 抽样规则（写死在 `src/prepare_data.py`）

1. 每个学科把 val 题号升序排好；
2. 学科按上表固定顺序遍历，共用一个 `random.Random(SEED=42)`；
3. 每科 `sample(qids, 40)`，抽完再按题号升序回排；
4. 输出按 `(subject, qid)` 排序，UTF-8、`indent=2`、LF 换行，**文件里不放时间戳**；
5. 少样本池：每科取 dev 前 3 题（dev 固定 5 题、顺序固定），评测时固定取前 2 题。

因此"同输入必得同 md5"，任何人重跑都应该得到完全相同的两个文件。

## 4. 防泄露自检（脚本内置，失败即退出）

- 评测集内部无重复题（按 `split + subject + qid` 判重；注意 val 与 dev 各自从 0 编号，跨划分必然重复）；
- 少样本池与评测集**没有相同题干**（这才是真正的泄露检查）；
- 评测集内部没有题干完全相同的题；
- 每科恰好 40 题、总 200 题、学科 5 个。

### 5.1 已知数据瑕疵：一对同题干、答案矛盾的题

`college_economics` 的 **qid 5 与 qid 54** 题干和四个选项完全相同，但参考答案一个是 **D**、一个是 **C**：

> 兰德只买激光唱片和棒棒糖，他有固定收入，不能借钱，当他沿着预算约束移动时____
> A. 激光唱片的价格在改变，而其收入和棒棒糖的价格不变
> B. 棒棒糖的价格在改变，而其收入和激光唱片的价格不变
> C. 激光唱片和棒棒糖的价格在改变，而其收入不变
> D. 激光唱片和棒棒糖的价格及其收入都不变

这是 C-Eval 原始数据集自带的标注矛盾，**不是**抽样引入的。

处理方式：**两题都保留**（删掉任何一题都等于按内容挑题），在 `subset_manifest.json` 的
`duplicate_stem_groups` 字段里留痕，并在结果分析里说明：这一对题最多只能答对一题，
对 200 题分母的影响是 ±0.5 个百分点。它也可以作为"数据质量"类错题案例写进报告。
